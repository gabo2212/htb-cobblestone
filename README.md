# HTB Cobblestone

Pentest tooling and methodology artifacts for the **Hack The Box machine Cobblestone** (difficulty: **Medium**).

## Contents

- `scripts/` — clients and exploit helpers (LFI chain, XSS, Cobbler, voting app)
- `artifacts/` — non-sensitive recon and LFI extract samples (see `.gitignore`)

## Setup

1. Add HTB VPN config under `config/` locally (not committed).
2. Run `scripts/vpn_connect.sh` when connected to the lab VPN.
3. Session notes belong in `notes/`; flags, hashes, dumps, and cookies stay out of git.
